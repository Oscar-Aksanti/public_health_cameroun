# Analyse de données en santé publique avec R

## De la donnée brute au dashboard interactif

**Par Oscar Aksanti**

------------------------------------------------------------------------

## 📌 Présentation du projet

Ce projet simule un cas réel d’analyse de données en santé publique dans un pays d’Afrique subsaharienne francophone.

Vous êtes dans le rôle d’un analyste junior travaillant avec un ministère de la santé.\
Les données proviennent de consultations médicales enregistrées dans plusieurs centres de santé.

👉 Comme dans la vraie vie, les données sont **sales et incohérentes**.

------------------------------------------------------------------------

## 📊 Contexte

Le dataset contient volontairement des problèmes fréquents en entreprise :

- Valeurs manquantes (NA)
- Doublons
- Fautes de frappe
- Catégories incohérentes
- Dates mal formatées
- Valeurs aberrantes

🎯 Objectif : transformer des données brutes en insights exploitables pour la prise de décision.

------------------------------------------------------------------------

## 🔁 Workflow Data Analyst

Ce projet suit le workflow classique d’un Data Analyst :

### 1. Import des données

Chargement du dataset brut.

### 2. Exploration

Comprendre la structure et la qualité des données.

### 3. Data cleaning

Nettoyage des données : - gestion des NA - suppression des doublons - correction des formats - harmonisation des catégories

### 4. Transformation

Création de nouvelles variables utiles pour l’analyse.

### 5. Analyse métier

Réponse aux besoins du ministère de la santé.

### 6. Visualisation

Création de graphiques pour faciliter la compréhension.

### 7. Statistiques descriptives

Analyse des tendances et distributions.

### 8. Dashboard interactif

Création d’une application web avec Shiny.

### 9. Reporting

Présentation des résultats de manière claire.

### 10. Recommandations

Transformation des données en décisions concrètes.
